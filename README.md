# 시각형 창고관리 시스템

가칭 **Warehouse Visual**. 실제 창고 형태를 2D 평면도로 구성하고, 배치된 랙을 선택하면 그 랙의 3D 구조와 물품 보관 위치를 확인하는 시스템입니다.

현재는 **1단계 공간 탐색 시제품**입니다. React 웹앱에서 2D 평면도의 두 샘플 랙을 선택하면 3D 구조와 보관 칸을 확인할 수 있습니다. 3D 상세는 초기 제품의 핵심이며, 2D를 완성한 뒤 전체를 3D로 교체하는 계획이 아닙니다.

## 실행과 검증

Node.js 24 환경에서 검증했습니다. 프로젝트 폴더에서 실행합니다.

```powershell
npm ci
npm run dev
```

표시되는 로컬 주소(기본 `http://127.0.0.1:5173`)를 엽니다. `npm run build`는 타입 검사와 배포 파일 생성을 수행하며, `npm test`는 도메인 테스트, `npm run test:e2e`는 설치된 Microsoft Edge를 이용한 브라우저 테스트입니다. 브라우저 테스트 서버는 자동 시작·종료됩니다.

지원 동작: 평면도 팬·줌·맞춤, 랙 선택, 3D 회전·줌, 칸 클릭·목록 선택, 단·행 필터, 시점 복원, 상세 닫기·재열기. 현재 배치는 고정 샘플이며 물품 등록·재고 테이블·배치 편집·지속 저장은 아직 없습니다.

## 확정 사항과 제안 구분

사용자와 합의한 방향은 다양한 랙 형태, 실제 창고에 맞춘 2D 배치, 선택한 랙의 3D 상세, 물품 위치 검색, 일반 재고 테이블입니다. PC 웹 기반 React·TypeScript·Vite, Konva, Three.js·React Three Fiber·Drei, Zustand를 적용했습니다. 저장·재고 단계의 Dexie·Zod·TanStack Table과 공동 사용 단계의 Fastify·PostgreSQL·Prisma는 채택할 계획이며 아직 설치하지 않았습니다. 제품명과 공동 사용 도입 시점은 미확정입니다.

다음 구현 단계는 랙 이동·회전·치수 입력 및 충돌 검사를 포함한 배치 편집입니다. 상세 계획과 현재 제한은 기술 문서와 작업 기록을 참고하세요.
