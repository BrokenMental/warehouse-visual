# 상세 제품·화면 설계

작성일: 2026-11-10. 상태: 제품 전체 설계와 단계별 구현 진행. 1단계 고정 샘플의 2D·3D 탐색을 구현했으며 아래 편집·검색·재고·저장 기능은 후속 범위다. 좁은 화면의 첫 시제품은 3D 상세를 평면도 아래에 배치한다.

## 1. 제품의 핵심

실제 창고 외곽과 구역을 2D 평면도로 만들고 다양한 랙을 원하는 위치와 방향에 배치한다. 랙을 누르면 해당 랙만 3D로 확인하고 정확한 물품 보관 칸을 찾는다. 표 형태의 재고 관리와 그래픽 탐색은 같은 데이터를 사용한다.

핵심 여정: 창고 설정 → 랙 구성·배치 → 칸에 물품 연결 → 물품 검색 → 평면도에서 랙 확인 → 3D에서 정확한 칸·단 확인.

초기 제품에서 제외하는 제안 범위: 전체 창고 3D 이동, 경로 최적화, ERP 연동, CAD/BIM 가져오기, 실시간 센서, 사진에서 랙 자동 생성. 필요성이 확인되면 별도로 설계한다.

## 2. 화면 구성

| 영역 | 내용과 동작 |
| --- | --- |
| 상단 | 창고 선택, 물품·SKU·위치 코드 검색, 조회/편집 전환, 저장 상태 |
| 왼쪽 | 구역 목록, 랙 목록, 검색 결과. 편집 시 랙 템플릿과 시설물 도구 |
| 중앙 | 2D 평면도, 축척, 랙 이름과 앞면 표시, 선택·검색 강조 |
| 오른쪽 | 선택 랙의 3D 상세, 방향·단수, 선택 칸의 물품과 수량 |
| 재고 화면 | 필터·정렬 가능한 표, 위치 보기, 물품 상세 |

넓은 화면은 평면도와 3D 상세를 함께 보여준다. 좁은 화면은 상세를 별도 화면으로 열되 닫을 때 평면도 확대율과 중심을 복원한다. 모바일의 복잡한 배치 편집 제공 여부는 첫 구현 후 판단한다.

## 3. 창고와 구역 편집

- 창고 이름, 가로·세로, 단위를 입력한다. 내부 치수는 mm, 사용자 입력은 m 또는 mm로 변환한다.
- 사각형으로 시작하고 꼭짓점을 추가·이동해 ㄱ자 등 실제 외곽을 만든다. 자기 교차, 면적 0, 중복 꼭짓점은 저장할 수 없다.
- 창고 내부에 구역 다각형을 그리고 이름·색을 지정한다. 초기에는 구역 간 면적 중첩을 허용하지 않는다.
- 기둥·벽·출입구·통로를 별도 객체로 둔다. 통로와 출입구 확보 영역은 배치 금지 영역으로 설정할 수 있다.
- 창고 크기를 줄여 객체가 외부로 나가면 문제 객체 목록을 보여주고 저장을 막는다. 자동 축소하거나 삭제하지 않는다.
- 구역에 완전히 포함되지 않는 랙은 미지정 상태로 표시한다. 구역 경계 이동 시 귀속 변경을 미리 보여주며 영구 ID는 유지한다.

## 4. 다양한 랙 만들기

랙은 템플릿을 기반으로 만든 독립 인스턴스다. 모양은 그림만 바꾸는 것이 아니라 외형, 보관 칸, 접근 방향을 함께 정의한다.

| 유형 | 구성 | 도입 단계 |
| --- | --- | --- |
| 기본 선반형 | 너비·깊이·높이, 가로 열, 깊이 행, 높이 단 | 첫 수직 기능 구현 |
| 칸막이형 | 단별 다른 열 너비, 부분 칸막이, 서로 다른 단 높이 | 다양화 |
| 팔레트형 | 기둥·보·넓은 적재 칸, 칸별 허용 하중 정보 | 다양화 |
| 양면형 | 앞면/뒷면 독립 접근 및 칸 구분 | 다양화 |
| ㄱ자·ㄷ자 조합형 | 여러 모듈의 상대 위치·회전, 조합 전체 이동 | 다양화 |
| 특수형 | 캔틸레버 등 별도의 구조 생성 규칙 | 후속 검토 |

용어는 **열 = 좌우**, **행 = 앞뒤 깊이**, **단 = 아래에서 위**로 고정한다. 화면이 회전해도 번호는 뒤집히지 않는다. 양면 랙은 면을 먼저 선택한 뒤 해당 면의 고정 기준으로 번호를 읽는다.

랙 구성 입력: 이름·코드, 유형, 외형 치수, 기둥/선반 두께, 단별 바닥 높이·유효 높이, 열별 너비, 행별 깊이, 접근 면, 비활성 칸. 규칙적 격자는 빠른 생성 도구이고 최종 저장 단위는 개별 보관 칸이다.

조합형은 겹치지 않는 모듈을 결합한다. 단순한 큰 외접 사각형 대신 실제 모듈의 바닥 영역으로 충돌을 판단한다. 초기에는 자유로운 3D 메시 편집기를 만들지 않는다.

## 5. 2D 배치 조작

- 조회 모드: 드래그는 화면 이동, 휠/핀치는 확대·축소, 랙 클릭은 상세 열기다.
- 편집 모드: 랙 드래그는 배치 이동, 빈 공간 드래그는 화면 이동이다. 숫자 입력으로도 좌표·각도를 수정한다.
- 그리드 스냅과 90도 회전을 기본 제공하고 자유 회전은 후속으로 확장한다. 스냅 해제와 적용 간격을 표시한다.
- 이동 중 외곽 이탈·시설물·다른 랙과 충돌하면 경고 윤곽을 보여준다. 놓는 시점에 유효하지 않으면 이전 위치로 되돌린다.
- 랙 복제는 새 ID와 빈 재고로 생성한다. 재고까지 복제하지 않는다.
- 되돌리기/다시 실행은 배치 편집에 적용한다. 실제 입출고 이력은 편집 취소로 되돌리지 않는다.
- 저장 전 초안과 마지막 저장 상태를 구분한다. 저장 실패 시 초안을 유지하고 재시도할 수 있게 한다.

## 6. 3D 랙 상세

선택한 랙의 치수·칸·구조물로 3D를 생성한다. 기본 카메라는 랙 앞면과 윗면이 함께 보이는 사선이다. 회전·확대·정면/후면/측면·초기 시점 복원을 제공한다.

칸 선택 시 윤곽, 위치 코드, 단수와 물품 목록을 함께 표시한다. 검색 칸은 강조색과 텍스트 배지를 사용한다. 빈 칸도 선택 가능하며 물품을 배정할 수 있다. 실제 물품의 정밀 모델 대신 물품 종류·수량을 나타내는 단순 상자와 목록을 사용한다.

뒤쪽이나 높은 단에 숨은 검색 칸은 접근 면으로 카메라를 맞춘다. 선택 단만 보기와 비선택 구조물 반투명을 제공하되 원래 위치를 바꾸지 않는다. 가려진 칸을 관통 클릭으로 잘못 고르지 않도록 단/면 필터로 선택 범위를 좁힌다.

상세를 닫으면 평면도 상태를 유지한다. 3D 기능을 사용할 수 없으면 위치 코드·칸 목록·정면 격자로 정보를 제공하고 3D 사용 불가 상태를 안내한다.

## 7. 검색과 테이블 연결

검색 키: 품명, SKU, 바코드 문자열, 위치 코드. 초기에는 대소문자·앞뒤 공백을 정규화한 정확 일치와 부분 일치를 지원하고 정확 일치를 먼저 표시한다.

1. 검색 결과는 물품별 총수량과 보관 위치별 수량을 제공한다.
2. 결과 위치를 선택하면 평면도가 해당 랙을 화면 안으로 이동·확대한다.
3. 해당 랙의 3D 상세를 열고 정확한 칸을 선택한다.
4. 위치 경로와 선택 수량을 표시한다. 예: `본창고 / A구역 / R03 / 앞면 / 2열 / 1행 / 4단`.
5. 여러 위치가 있으면 목록에서 전환한다. 첫 위치만 강조하고 나머지를 숨기지 않는다.

품목은 등록됐지만 재고가 없으면 ‘재고 없음’, 재고는 있지만 위치가 미지정이면 ‘위치 미지정’으로 구분한다. 결과 없음, 삭제된 위치, 검색 중 데이터 변경도 빈 화면 대신 원인을 표시한다.

재고 테이블은 품명·SKU·수량·단위·창고·구역·랙·칸·최근 변경일을 표시한다. 품목 합계 보기와 위치별 보기를 구분한다. 테이블의 ‘위치 보기’는 같은 선택 흐름을 재사용한다. 그래픽에서 칸을 선택하면 해당 칸의 재고 목록을 연다.

## 8. 재고 관리

품목 등록, 위치 배정, 입고, 출고, 위치 간 이동, 실사 조정을 단계적으로 추가한다. 같은 품목이 여러 칸에 있을 수 있고 한 칸에 여러 품목을 담을 수도 있다. 칸별 혼재 허용 여부는 설정으로 제한할 수 있다.

이동은 출발 감소와 도착 증가를 한 작업으로 처리한다. 음수 재고, 다른 단위의 무단 합산, 삭제된 칸 배정을 거부한다. 실사 조정에는 사유를 남긴다. 로트·유통기한·시리얼 관리와 예약 재고는 후속 범위로 둔다.

## 9. 구조 변경과 데이터 보호

재고가 있는 랙의 물리 위치 이동은 칸 ID를 유지한다. 단·열 축소나 모듈 삭제로 칸이 사라지는 경우에는 영향 목록과 재고 이전 대상을 먼저 정한다. 이전이 끝나기 전에는 적용을 거부한다. 과거 이력이 있는 칸은 비활성화하고 이력에서 참조 가능하게 유지한다.

템플릿 변경은 새 버전으로 만든다. 기존 랙에 적용할 때는 구조 차이와 영향을 받는 칸을 확인한다. 창고·구역·랙 이름 변경은 표시 경로만 바꾸며 이전 거래의 당시 위치 표시는 이력에 보존한다.

## 10. 검토할 결정

- 첫 실행 환경: 데스크톱 브라우저 중심인지, 설치형 앱도 필요한지
- 실제 랙 예시와 우선 제공할 유형, 양면·깊이 행 사용 여부
- 한 명의 로컬 사용인지, 여러 직원의 공동 사용인지
- 최대 창고·랙·칸·품목 규모, 하중·부피 관리의 필요 수준
- 바코드 입력 장치, 기존 엑셀 가져오기와 내보내기 필요 시점

이 항목들은 현재 문서 작성을 막지 않는다. 구현 단계에서 해당 결정이 필요한 시점에 확인한다.
