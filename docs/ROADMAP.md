# 단계별 구현 계획

각 단계는 작은 동작을 실제로 확인한 뒤 확장한다. 2026-11-10 사용자 요청으로 구현에 착수했다. 0단계 문서와 1단계 핵심 연결을 구현·검증했다. 2~6단계는 미구현이다.

| 단계 | 구현 내용 | 완료 기준 |
| --- | --- | --- |
| 0. 설계 | 요구, 화면, 공통 모델, 프로젝트 규칙 | 문서 작성 및 연결 확인 |
| 1. 핵심 연결 | 사각 창고, 다른 크기·칸 구성의 기본 랙 2개, 2D 선택, 3D 상세 | 각 랙을 누르면 서로 다른 실제 구조가 열리고 칸 번호 일치 |
| 2. 배치 편집 | 모드 구분, 이동·90도 회전, 치수 입력, 스냅, 충돌, undo/redo | 옮기거나 회전해도 3D 구조와 칸 ID 유지, 유효하지 않은 배치 거부 |
| 3. 실제 창고·랙 다양화 | 다각형 외곽, 구역·시설물, 칸막이·팔레트·양면·모듈 조합 | ㄱ자 창고와 ㄱ자 랙 재현, 양면·단별 칸 선택 정확 |
| 4. 물품 찾기 | 품목·칸 연결, 여러 위치 검색, 카메라 이동, 3D 강조, 재고 표 | 같은 품목을 여러 칸에 배정하고 각 검색 결과에서 정확히 찾아감 |
| 5. 저장·재고 작업 | 지속 저장, 가져오기/내보내기, 입출고·이동·실사, 구조 변경 보호 | 재실행 후 복원, 실패·중복 요청에서도 수량과 이력 일치 |
| 6. 운영 준비 | 실제 창고 데이터 검수, 성능·접근성·지원 환경 확인 | 사용자 시나리오와 지원 규모를 측정해 기록 |

단계 1부터 3D 상세가 포함된다. 전체 창고 3D는 별도 후속 기능이다. 단계 1~4의 임시 데이터는 시제품 데이터로 표시하며 단계 5 전에는 실제 재고 운영에 사용하지 않는다.

## 첫 구현에서 확인할 장면

1. 랙 A는 3열·1행·4단, 랙 B는 2열·2행·3단으로 만든다.
2. 평면도에서 A를 누르고 3D의 2열·1행·4단을 선택한다.
3. B를 누르면 A의 선택과 구조가 남지 않고 B의 구조가 열린다.
4. 평면도를 확대·이동한 뒤 상세를 닫아도 평면도 시점이 유지된다.
5. 각 랙의 앞면 표식과 3D 기본 방향이 일치한다.

## 후속 확장 후보

공동 작업과 권한, 바코드 장치, 엑셀 연동, 로트·유통기한, 전체 창고 3D, 피킹 경로, CAD 도면 가져오기는 필요성과 우선순위를 확인한 후 각각 설계한다.
